# FinPay Architecture

## Project Overview

FinPay is an independent portfolio project
representing a merchant payment operations platform.

## Frontend

- React and TypeScript
- Vite
- React Router
- TanStack Query
- CSS Modules

## Architecture Principles

- Feature-first organization
- Clear separation of UI and business logic
- Centralized route configuration
- Reusable application shell
- API-driven feature development
- Type-safe contracts
- Testable user interactions

## Testing Strategy

- Vitest for test execution
- React Testing Library for component tests
- User Event for interaction testing
- Memory Router for route integration testing

## Error Handling

- Route-level error boundaries
- Separate 404 page
- User-safe error messages

## Future Development

- Backend REST API
- PostgreSQL
- Shared contracts
- Authentication and RBAC
- CI/CD integration
